🌐 Acceso al Panel

Diferentes formas de acceder al panel desde cualquier dispositivo.

💻 Servidor

🏠 Red Local (WiFi/Ethernet)

Accede desde cualquier dispositivo en la misma red. No requiere configuración adicional.

📱 Para acceder desde tu celular:
  1. Conecta el celular al mismo WiFi que el servidor
  2. Abre el navegador y escribe una de las URLs de arriba
  3. Inicia sesión con tus credenciales

☁️ Cloudflare Tunnel No configurado

Acceso desde cualquier lugar del mundo con HTTPS automático. Gratis y sin abrir puertos.

🔧 Configuración:
  1. Crea cuenta en Cloudflare Zero Trust (gratis)
  2. Ve a Access → Tunnels → Create a tunnel
  3. Elige "Cloudflared" y copia el comando
  4. Ejecuta el comando en tu Raspberry Pi
  5. Configura un dominio público

🔒 Tailscale No configurado

Red privada entre tus dispositivos. Muy seguro, solo acceden dispositivos autorizados.

🔧 Configuración:
  1. Crea cuenta en tailscale.com
  2. Instala en Raspberry Pi: curl -fsSL https://tailscale.com/install.sh | sh
  3. Ejecuta: sudo tailscale up
  4. Instala en tus otros dispositivos

📲 Acceso rápido con QR

Escanea este código con tu celular para abrir el panel rápidamente.

📱 Cómo usar:
  1. Selecciona la URL que quieres codificar
  2. Abre la cámara de tu celular
  3. Apunta al código QR
  4. Toca la notificación para abrir el panel
