🌐 Acceso al Panel

Diferentes formas de acceder al panel de administración desde cualquier dispositivo.

💻 Información del Servidor

🏠 Red Local (WiFi/Ethernet)

Accede desde cualquier dispositivo en la misma red. No requiere configuración adicional ni internet.

📱 Para acceder desde tu celular:
  1. Conecta el celular al mismo WiFi que el servidor.
  2. Abre el navegador y escribe una de las URLs de arriba.
  3. Inicia sesión con tus credenciales.

🌍 Acceso Remoto No configurado

Accede desde cualquier lugar del mundo. El bot utiliza LocalTunnel por defecto, pero puedes configurar Cloudflare o Tailscale.

💡 Nota: Si usas LocalTunnel, el bot genera y guarda esta URL automáticamente al iniciar. Para opciones más estables, revisa la documentación de Cloudflare Zero Trust o Tailscale.

🔧 Configuración Avanzada

Opciones para mejorar la estabilidad del acceso remoto si LocalTunnel presenta limitaciones.

☁️ Cloudflare Tunnel (Recomendado para producción):
  1. Crea cuenta en Cloudflare Zero Trust.
  2. Ve a Access → Tunnels → Create a tunnel.
  3. Instala `cloudflared` en la Raspberry Pi.
  4. Copia la URL pública y pégala en el panel de la izquierda.
🔒 Tailscale (Red privada segura):
  1. Instala en Raspberry Pi: curl -fsSL https://tailscale.com/install.sh | sh
  2. Ejecuta: sudo tailscale up y autoriza el dispositivo.
  3. Usa la IP `100.x.y.z` asignada por Tailscale.
